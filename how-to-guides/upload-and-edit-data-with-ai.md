# Upload and edit data with AI

#### Summary

Sortment AI supports uploading data files (such as CSV and Excel files) directly in chat. Once a file is uploaded, you can instruct the AI to create new tables or update existing tables using the uploaded data.

In the chat composer, choose **Add image or file** and select the file. Wait for the attachment to appear before asking Sortment to use it. A filename can contain accented or other non-ASCII characters, such as `résumé.csv`; you do not need to rename it solely for that reason. If the upload fails, report the file type and the error rather than sharing a file containing customer data.

**Example**

> "Hi Sortment, scan the uploaded CSV in chat and append the users in the file to my Anniversary Event list."

#### Limitations

* Sortment AI can only create or modify tables that have been uploaded to and are managed within Sortment.
* It cannot directly modify or overwrite data stored in your connected data warehouse.
* Any changes are limited to tables available within the Sortment platform.
